TOPIC 1: Primary Characteristics & 5 Computer Generations

Deep architectural breakdown of computational traits and hardware technology evolution.

Core Architectural Characteristics & Metrics

Speed MFLOPS / TFLOPS

Modern digital computers operate at clock frequencies exceeding 5 GHz, executing billions of instructions per second. Speeds are quantified in nanoseconds (10⁻⁹s) and picoseconds (10⁻¹²s) per cycle.

Accuracy 64-bit IEEE 754

Computers deliver absolute mathematical precision based on binary arithmetic algorithms. Errors arise strictly from flawed user inputs or software bugs, governed by the GIGO (Garbage In, Garbage Out) principle.

Diligence Zero Fatigue

Unlike humans, electronic processors operate continuously for weeks or years without fatigue, loss of concentration, or degradation in calculation speed.

Versatility Multi-Tasking

Ability to execute vastly different tasks sequentially or concurrently—switching from complex matrix physics calculus to real-time video streaming within microseconds.

Storage Capacity Terabytes / Petabytes

Hierarchical memory organization combining high-speed volatile registers and primary RAM with massive non-volatile NVMe solid-state drives and cloud repositories.

Automation Autonomous Logic

Once a stored program is loaded into main memory, execution proceeds autonomously under Control Unit direction without manual operator intervention.

TOPIC 2: Data, Instruction & Control Signal Flow in Architecture

Functional block diagram interaction between CPU registers, RAM memory, and system bus lines.

CPU Internal Subsystems

  • Program Counter (PC): Holds memory address of next instruction to be fetched.
  • Memory Address Register (MAR): Holds memory location currently being read/written.
  • Memory Data Register (MDR): Stores data coming from or written to main memory.
  • Instruction Register (IR): Stores fetched instruction for Control Unit decoding.
  • Accumulator (ACC) / ALU: Executes math/logic and stores immediate calculation results.

System Bus Triad

  • Data Bus (Bidirectional): Transfers raw data and opcode bytes between CPU, RAM, and I/O. Bus width (e.g. 64-bit) determines word size.
  • Address Bus (Unidirectional): Transmits target memory addresses from CPU to address decoders. Width determines max RAM capacity (2^N bytes).
  • Control Bus (Bidirectional): Transmits Read/Write enable commands, system clock ticks, and interrupt requests.

Memory & I/O Interfaces

  • Main Memory (RAM): Addressable cell matrix storing active program instructions and variables.
  • Memory-Mapped I/O: I/O device ports share address space with RAM; read/write via standard memory instructions.
  • Isolated I/O: I/O ports use separate address space and dedicated bus commands (IN / OUT).

TOPIC 3: Campus Automation - Scanning Devices & Card Readers

Deployment architecture for automated student attendance and library management.

Optical Data Scanners (Barcode / OMR)

Barcode Readers: Laser diode (650nm) or 2D area CCD sensors project light on alternating dark lines/spaces, measuring reflected light differential. Supports 1D UPC/Code128 and 2D QR codes with error correction.

OMR (Optical Mark Recognition): Transmits high-intensity light through pre-printed position matrices to measure light absorption in marked pencil/pen bubbles for automated paper assessment.

Electronic Smart Card Readers (RFID / NFC)

RFID Readers: Employs 13.56 MHz high-frequency (ISO 14443 / ISO 15693) electromagnetic induction. Reader coil generates an RF field powering passive card microchips within 10cm range.

Smart Cards & Security: Embedded secure microcontroller chips storing encrypted student UIDs using AES-128 key diversification and 3-pass mutual authentication to prevent cloning.

TOPIC 5: Point-and-Draw Devices vs Graphics Digitizers

Coordinate tracking mechanisms, pressure sensitivity, and application suitability.

Point-and-Draw Devices (Mouse / Trackball)

  • Coordinate Tracking: Uses Relative Delta Vectors. Optical CMOS sensors capture floor movement frames, outputting relative displacement offsets (ΔX, ΔY).
  • Pressure & Tilt: Zero pressure sensitivity or tilt tracking capability. Binary button switches only.
  • Primary Application: Standard Desktop GUI, web browsing, menu selection, and basic CAD navigation.

Graphics Digitizers / Drawing Tablets

  • Coordinate Tracking: Employs Absolute EMR (Electromagnetic Resonance) Grid. Sensor loops map physical tablet corners directly to display pixels.
  • Pressure & Tilt: Capacitive micro-actuator styluses detect up to 8192 pressure levels and ±60° tilt angle.
  • Primary Application: Digital artwork, 3D anatomical modeling, medical illustration, and precision vector CAD.

TOPIC 7: Facial Recognition vs Voice Recognition Biometrics

Operational reliability and security vulnerability critique in high-noise, public spaces.

Vision-Input (Facial Biometrics)

Mechanism: Uses 3D structured light dot projection or Near-Infrared (NIR) time-of-flight sensors to construct 80+ nodal facial mesh points.

Vulnerabilities:

• Ambient solar IR interference washes out optical sensors outdoors.

• Presentation attacks via high-resolution 3D silicone masks or deepfake projection.

Voice-Input (Acoustic Biometrics)

Mechanism: Extracts Mel-Frequency Cepstral Coefficients (MFCCs) and vocal tract resonance harmonics to create unique acoustic voiceprints.

Vulnerabilities:

• High ambient background noise severely degrades Signal-to-Noise Ratio (SNR).

• Replay attacks & generative AI voice cloning (e.g. Tacotron / ElevenLabs).
